# SALARX Street Racer

**SALARX Street Racer** is a mobile-first arcade racing game built by **Salar**.

The SALARX-OS repository has been transformed from the old desktop dashboard concept into a focused racing experience designed to work on phones and PCs.

## Features

- Street racing gameplay
- Touch controls for phones
- Arrow keys / WASD controls on PC
- Nitro boost
- Multiple unlockable cars
- Coins and persistent progression
- Garage and car selection
- Car shop
- Missions
- Best score tracking
- Traffic obstacle system
- Distance and score tracking
- Speedometer and nitro HUD
- Dark cinematic UI
- PWA install support
- Browser-local save system
- Offline caching through a service worker
- Settings and reset-save controls

## How to play

**PC**
- Left / Right or A / D — steer
- Down / S — brake
- Space / N — nitro

**Phone**
- Use the on-screen steering, brake and nitro buttons.

Avoid traffic, survive longer, collect rewards, and use coins to unlock faster cars.

## Run

Open `index.html` in a modern browser or enable GitHub Pages for the repository.

## Project files

- `index.html` — game, UI and gameplay
- `manifest.json` — PWA configuration
- `sw.js` — offline cache
