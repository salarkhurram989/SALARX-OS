# SALARX OS

**SALARX OS** is a futuristic browser-based desktop environment by **Salar**.

It turns a normal web page into a lightweight personal workspace with apps, a dock, productivity tools, a terminal, AI integration space and a gaming hub.

## ✨ Features
- Futuristic glassmorphism desktop
- Responsive phone + desktop UI
- AI Command Center
- FileBox workspace and search
- Local autosaving Notes
- Built-in Terminal
- GameHub for projects such as Penalty Shooter
- Toolbox with calculator + 25-minute focus timer
- System Settings
- Live clock and date
- Boot screen
- Keyboard ESC shortcut
- No account required for the core experience
